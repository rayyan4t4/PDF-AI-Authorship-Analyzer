# Models Directory

## Active Model

**Model ID**: `roberta-base-openai-detector`  
**Source**: Hugging Face — OpenAI GPT-2 Output Detector  
**Architecture**: RoBERTa-base fine-tuned as a binary classifier

### What this model does

This model was fine-tuned by OpenAI on GPT-2 generated text.  
It predicts a probability that a given text passage was written by a language model.

**Label 0**: Human-written  
**Label 1**: Machine-generated (AI)

### Limitations

- Trained primarily on GPT-2 output. It generalizes imperfectly to GPT-3/4, Claude, Gemini, etc.
- Performance degrades on short texts (< 100 tokens).
- Texts that have been paraphrased, edited, or mixed with human writing are harder to classify.
- The model is **not scientifically validated** as an academic-integrity tool.
- It can produce false positives (flagging human writing) and false negatives (missing AI writing).

### Changing the Model

Set `MODEL_NAME` in your `.env` file to any Hugging Face sequence classification model.

Examples of alternative models you can substitute in V2:
- `Hello-SimpleAI/chatgpt-detector-roberta`
- `andreas122001/roberta-academic-detector`
- A custom fine-tuned DeBERTa or RoBERTa model

The application will automatically use any model whose output is a 2-class
(Human / AI) sequence classification head.

### Future: Custom Classifier

For V2, you can train a custom classifier using labeled data:
- Human-written documents
- AI-generated documents (GPT-4, Claude, Gemini, Llama, etc.)
- AI-generated and human-edited documents
- Paraphrased AI text
- Documents generated by different AI models

Recommended starting point: fine-tune DeBERTa-v3-base on your labeled dataset.
